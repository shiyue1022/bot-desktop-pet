## 中文

bot 桌宠首个公开版本，支持 Windows x64。

- 点击互动、拖动效果、四边半隐藏及空闲跳动。
- 托盘换肤、大小调整、Grok 连接状态。
- 问号思考、侧视笔记本、两个小球手敲键盘，结束后恢复空闲。
- 下载 ZIP 后完整解压，运行 `bot.exe`，或用 `Install.cmd` 创建桌面快捷方式。
- Grok 联动已在 0.78.1 验证，需通过带本机调试参数的快捷方式启动；详见仓库说明。

## English

First public release of bot Desktop Pet for Windows x64.

- Click interactions, picked-up drag pose, half-hidden edge docking and idle hopping.
- Tray customization, size controls and Grok connection indication.
- Question-mark thinking, an angled laptop with two ball-shaped typing hands, and automatic return to idle.
- Extract the complete ZIP and run `bot.exe`, or use `Install.cmd` to create a desktop shortcut.
- Grok sync was tested with 0.78.1 and needs the documented local-debugging shortcut arguments. See the repository README for details.

This build is unsigned. No Grok account data or conversations are included.
